# HamacWeb — نسخة تشغيل محلية

تحتوي هذه الحزمة على كود المشروع الحالي ونسخاً محلية من الصور والوسائط المستخدمة في الواجهة داخل `client/public/assets/`.

## التشغيل

ثبّت Node.js 22 أو إصداراً حديثاً، ثم شغّل الأوامر التالية من مجلد المشروع:

```bash
pnpm install
pnpm dev
```

بعدها افتح الرابط الذي يظهر في الطرفية، وغالباً يكون `http://localhost:3000`.

## ملاحظات

تُشير نسخة التصدير المحلية إلى `/assets/`، لذلك ستظهر الوسائط من دون اعتماد على روابط التخزين الخارجية. نموذج طلب الوصول يحتاج متغير `DATABASE_URL` إذا أردت حفظ الطلبات في قاعدة البيانات عند التشغيل المحلي. لا تتضمن الحزمة `node_modules` أو أي ملف أسرار؛ ثبّت الاعتمادات محلياً عبر `pnpm install`.
